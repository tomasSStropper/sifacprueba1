# sifacprueba1

Proyecto de NetBeans (Ant). Las clases de la prueba están en `src/prueba1`.

- **C.1** `prueba1.entidades`: `Documento`, `FacturaContado`, `FacturaCredito`, `NotaCredito` y `PruebaDocumentos`. Las pruebas JUnit están en `test/prueba1/entidades/DocumentoTest.java`.
- **C.2** `prueba1.estructuras`: `NodoEstado`, `HistorialDocumento` y `PruebaHistorial`.
- **C.3** `prueba1.colecciones`: `DocumentoIndice` y `PruebaIndice`.

Cada clase `Prueba*` se ejecuta con clic derecho > Run File. Las pruebas se ejecutan con clic derecho sobre el proyecto > Test.
